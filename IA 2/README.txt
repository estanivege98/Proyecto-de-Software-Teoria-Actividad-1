JARDÍN & VERDE — DEMO ESTÁTICA ACCESIBLE

La versión actual sigue buenas prácticas orientadas a WCAG 2.2 nivel AA:
- HTML semántico y landmarks.
- lang="es" y jerarquía de encabezados.
- Enlace para saltar al contenido.
- Navegación completa por teclado.
- Foco visible y reforzado.
- Nombres accesibles específicos para los enlaces "+ info".
- Alt descriptivo para las imágenes.
- Decoraciones ocultas a lectores de pantalla.
- Selector de categorías mediante radio nativo + CSS, sin JavaScript.
- Etiquetas reales asociadas a todos los campos.
- autocomplete/inputmode para formularios.
- Respeto de prefers-reduced-motion.
- Soporte básico de forced-colors/alto contraste.
- Formulario marcado explícitamente como demostrativo y sin envío.
- Contraste reforzado.

Importante: WCAG es un estándar de conformidad. Una declaración formal de conformidad
requiere evaluar también los contenidos finales, imágenes, PDFs, navegador, servidor y
otros componentes del proyecto con herramientas automáticas y pruebas manuales.
